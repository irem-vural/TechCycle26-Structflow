# StructFlow Toolbar SVG Icon Pack

Bu paket StructFlow bina modülü toolbar'ı için hazırlanmış gerçek SVG ikonlardan oluşur.

## İçerik
- 19 ayrı SVG ikon
- `structflow-toolbar-icons-sprite.svg` sprite dosyası
- `structflow-toolbar-icon-pack-preview.svg` önizleme paftası

## Renkler
- Primary accent: #2CF2DC
- Secondary neutral: #D5D9DC
- Dark UI background: #050B10 / #0B1117
